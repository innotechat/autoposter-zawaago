# Brand Asset Pipeline

The supplied Zawaago and InnoTech artwork has been reviewed and converted into transparent-background, scalable SVG assets for the social creative pipeline.

## Assets
- `/brand/zawaago-logo-final.svg`
- `/brand/innotech-logo-final.svg`

## Composition rules
- Preserve the logo aspect ratio.
- Keep the logo inside a social-safe margin.
- Use a smaller relative footprint on portrait creatives so the logo does not compete with the focal subject.
- Prefer bottom-right by default, with user-selectable corner placement.
- Never ask the image model to render the logo; the real supplied asset is applied separately.
- The branded output should be treated as the publishable asset, while the generated original remains available for regeneration/reuse.
